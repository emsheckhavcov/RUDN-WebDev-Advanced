## 1. Серверный сервис и HTTP-слои

- [x] 1.1 Добавить асинхронную операцию сервиса, которая меняет только `isDone` карточки по `id` и возвращает обновлённую карточку либо признак отсутствия; проверить типизацию сервера и оба результата операции.
- [x] 1.2 Добавить PATCH-контроллер, который вызывает сервис и отвечает `200` с карточкой или `404` при отсутствии `id`; проверить ответы на существующую и отсутствующую карточку.
- [x] 1.3 Добавить middleware, принимающее только boolean `isDone` и возвращающее JSON `400` для неверного или отсутствующего значения; проверить, что некорректный запрос не меняет карточку.
- [x] 1.4 Подключить `PATCH /:id` в роутере после точных маршрутов и передать middleware перед контроллером; проверить итоговые URL через HTTP-запросы.
