## Why

У карточек уже есть признак `isDone`, который определяет их отображение и работу фильтра выполненных карточек, но пользователь не может изменить этот признак. Из-за этого нельзя отмечать карточки выполненными или возвращать их в работу, а фильтр полезен только для карточек, отмеченных заранее.

## What Changes

- Добавить управление отметкой выполнения на карточке: пользователь сможет поставить и снять её.
- Добавить `PATCH /cards/:id` с телом `{ "isDone": boolean }` для изменения только признака выполнения.
- Выбрать `PATCH`, потому что запрос изменяет одно поле существующей карточки, а не заменяет весь ресурс.
- При успешном обновлении возвращать статус `200` и обновлённую карточку.
- Проверять значение `isDone` в middleware; при отсутствующем или не boolean значении отвечать `400`.
- Если карточка с указанным `id` не найдена, отвечать `404`; решение о HTTP-статусе принимает контроллер, сервис сообщает только результат операции.
- Сохранять изменённый признак в серверном состоянии, чтобы он оставался после обновления страницы.

## Capabilities

### New Capabilities

- `card-completion`: изменение признака выполнения карточки с доски и серверный контракт обновления `isDone`.

### Modified Capabilities

Нет.

## Impact

- Серверные сервис карточек, контроллер, роутер и middleware в `server/`.
- Клиентский API, компонент карточки и обновление данных React Query в `client/`.
- Новый endpoint `PATCH /cards/:id`; через существующий Vite proxy клиент будет обращаться к `/api/cards/:id`.
