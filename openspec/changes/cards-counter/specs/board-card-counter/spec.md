## Purpose

Эта возможность позволяет пользователю видеть общее количество карточек доски рядом с её названием, в том числе во время загрузки и при пустом списке.

## ADDED Requirements

### Requirement: Отображать общее количество карточек доски
Система SHALL отображать рядом с названием доски количество всех карточек, включая выполненные. Фильтр скрытия выполненных карточек MUST NOT влиять на это количество.

#### Scenario: Учитываются выполненные карточки
- **WHEN** на доске есть выполненные и невыполненные карточки
- **THEN** счётчик показывает общее количество всех карточек независимо от состояния фильтра скрытия выполненных

#### Scenario: Список карточек загружается
- **WHEN** список карточек ещё загружается
- **THEN** вместо числового значения счётчика отображается многоточие (`…`)

#### Scenario: Список карточек пуст
- **WHEN** список карточек успешно загружен и не содержит карточек
- **THEN** счётчик показывает `0`

#### Scenario: Карточка добавлена
- **WHEN** новая карточка успешно добавлена на доску
- **THEN** счётчик обновляется и показывает общее количество карточек с учётом добавленной
