## Purpose

Эта возможность позволяет пользователю удалить выбранную карточку с доски и убедиться, что результат удаления сохранён, а не только скрыт до перезагрузки страницы.

## Requirements

### Requirement: Удаление карточки с доски
Система SHALL предоставлять для каждой карточки действие удаления. Перед отправкой запроса на удаление система MUST запросить подтверждение. После успешного удаления карточка SHALL исчезнуть с доски без перезагрузки страницы. Если удаление завершается ошибкой, карточка MUST оставаться на доске, а пользователь MUST получить сообщение об ошибке. Сервер SHALL удалять карточку по `id` из URL запроса `DELETE /cards/:id` и отвечать статусом `204` без тела при успешном удалении. Если карточка с таким `id` отсутствует, сервер SHALL отвечать статусом `404` и JSON с описанием ошибки. Неизвестный маршрут SHALL возвращать статус `404` и JSON. Необработанная ошибка сервера SHALL приводить к статусу `500` и JSON.

#### Scenario: Запрос подтверждения удаления
- **WHEN** пользователь выбирает действие удаления карточки
- **THEN** система показывает запрос подтверждения для этой карточки и не отправляет запрос на удаление до подтверждения

#### Scenario: Отмена удаления
- **WHEN** пользователь отменяет запрос подтверждения
- **THEN** карточка остаётся на доске и запрос на удаление не отправляется

#### Scenario: Удаление подтверждено и выполнено успешно
- **WHEN** пользователь подтверждает удаление и сервер успешно удаляет карточку
- **THEN** сервер удаляет карточку с указанным `id`, отвечает `204` без тела, а карточка исчезает с доски без перезагрузки и не появляется снова после обновления данных

#### Scenario: Удаление неизвестной карточки
- **WHEN** сервер получает `DELETE /cards/:id` для отсутствующего `id`
- **THEN** сервер отвечает статусом `404` и JSON с описанием ошибки

#### Scenario: Неизвестный маршрут
- **WHEN** сервер получает запрос по маршруту, который не зарегистрирован
- **THEN** сервер отвечает статусом `404` и JSON, а не HTML-страницей

#### Scenario: Необработанная ошибка сервера
- **WHEN** при обработке запроса возникает ошибка, не обработанная маршрутом
- **THEN** сервер отвечает статусом `500` и JSON с описанием внутренней ошибки

#### Scenario: Ошибка удаления
- **WHEN** пользователь подтверждает удаление, но сервер не может удалить карточку или запрос завершается ошибкой
- **THEN** карточка остаётся на доске, а система сообщает пользователю, что удалить её не удалось
